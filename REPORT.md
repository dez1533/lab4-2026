## 2. Відповідь на контрольне запитання

**Запитання:** `Яка різниця між методами `re.match()` та `re.search()`?`

**Відповідь:**

`Основна відмінність між методами `re.match()` та `re.search()` полягає в тому, де саме в рядку вони шукають відповідність заданому регулярному виразу.
Метод `re.match()`
Принцип роботи: Перевіряє наявність збігу виключно на самому початку рядка (з індексу 0).
Поведінка: Якщо рядок починається з шуканого патерну, метод повертає об'єкт `Match`. Якщо шуканий текст знаходиться навіть на один символ далі від початку, `re.match()` одразу поверне `None`.
Коли використовувати: Коли потрібно строго перевірити, чи починається рядок з певного префікса, або коли шаблон містить маркери початку рядка (`^`).
Метод `re.search()`
Принцип роботи: Сканує весь рядок зліва направо і шукає перший збіг у будь-якому місці тексту.
Поведінка: Як тільки метод знаходить перше входження, що відповідає регулярному виразу, він зупиняється і повертає об'єкт `Match`. Якщо патерн взагалі відсутній у рядку, повертається `None`.
Коли використовувати: Коли потрібно знайти підрядок (наприклад, номер телефону, окреме слово чи email) всередині більшого масиву тексту, незалежно від його позиції.
Приклад коду для демонстрації:
```python
import re

text = "Аналіз тексту з використанням Python"

# Спроба знайти слово "тексту", яке знаходиться всередині рядка
match_result = re.match(r"тексту", text)
search_result = re.search(r"тексту", text)

print("--- Пошук слова 'тексту' ---")
print(f"re.match(): {match_result}") # Поверне None, бо рядок починається з "Аналіз"
print(f"re.search(): {search_result}") # Знайде збіг, бо сканує весь рядок
if search_result:
    print(f"Знайдено: '{search_result.group()}' на позиціях {search_result.span()}")

# Спроба знайти слово "Аналіз", яке знаходиться на початку рядка
match_start = re.match(r"Аналіз", text)

print("\n--- Пошук слова 'Аналіз' ---")
print(f"re.match(): {match_start}") # Знайде збіг
if match_start:
    print(f"Знайдено: '{match_start.group()}'")
`
